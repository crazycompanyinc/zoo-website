## What is ZOO?

ZOO Technologies is an AI-Native technology company building the next generation of trading tools, AI agent infrastructure, and SaaS products. Our mission is to democratize access to institutional-grade trading technology and AI-powered automation.

This repository contains the official ZOO website and landing pages, serving as the front door to our ecosystem of products and services.

## ✨ Features

- 🎨 **Stunning Landing Page** — cinematic dark-mode design with scroll animations
- 📈 **Trading Tools** — institutional-quality charts and backtesting
- 🤖 **AI Agents** — autonomous agent infrastructure for trading and operations
- 📝 **Blog** — SEO-optimized content for organic traffic
- 🛒 **Service Catalog** — SaaS products, templates, and consulting
- 💳 **Stripe Integration** — live payment processing

## 🚀 Quick Start

```bash
git clone https://github.com/crazycompanyinc/zoo-website
cd zoo-website
npm install
npm run dev
```

Visit `http://localhost:3000`

## 🛠️ Tech Stack

- **Frontend:** Next.js, React, TypeScript
- **Styling:** Tailwind CSS, CSS Modules
- **Deployment:** Vercel
- **Analytics:** Plausible
- **Payments:** Stripe
